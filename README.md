- 🧪 **Research:** papers and experiments behind the projects.
- 🛠️ **Now building:** a current view of what I am working on.

This repository is a portfolio showcase, not a general-purpose open-source package.

## Run locally

```bash
cd frontend
yarn install
yarn start
```

The site uses React and Tailwind CSS, with a small FastAPI backend in `backend/`.
