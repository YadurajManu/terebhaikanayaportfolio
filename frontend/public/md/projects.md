# Projects by Yaduraj Singh

## [Aarogya Setu](/projects/aarogya-setu)

Multi-tenant hospital SaaS — OPD/IPD queues, EMR, appointments, billing, pharmacy, diagnostics. 6-tier RBAC.

Technologies: Next.js 14, TypeScript, Prisma, PostgreSQL, Redis, Docker

## [Tollgate](/projects/tollgate)

Cost & usage observability for LLM APIs. Reverse proxy for OpenAI, Anthropic and OpenAI-compatible providers — one base URL for per-feature cost, caching, budgets and runaway-agent alerts.

Technologies: OpenAI API, Anthropic API, OpenRouter, Vercel

## [MuhDikhai](/projects/muhdikhai)

Omegle-style anonymous video chat. Full WebRTC peer lifecycle built manually over Socket.io. Sub-2s pairing.

Technologies: Node.js, TypeScript, WebRTC, Socket.io, PostgreSQL

## [CineVerse](/projects/cineverse)

Social film tracking — watchlists, ratings, reviews, discovery feeds. TMDB API across 500k+ titles.

Technologies: Next.js, Firebase, TMDB API, Nginx, PM2

## [SecondMind / CortX](/projects/cortx)

Cognitive OS on ESP32-S3 Sense. Voice → faster-whisper → local LLM → Coqui TTS. VAD firmware, Opus compression.

Technologies: ESP32-S3, FastAPI, Flutter, Neo4j, Qdrant

## [GBU Timetable](/projects/gbu-timetable)

Official iOS app for GBU students. Live home-screen widgets via WidgetKit. Real-time schedule updates.

Technologies: SwiftUI, Combine, WidgetKit

## [Maakosh](/projects/maakosh)

Maternal & neonatal health iOS app. Wearable sensor integration (MAX30100, EMG) for real-time vitals. Role-based.

Technologies: Swift, Firebase, ThingSpeak

## [Bolonyay](/projects/bolonyay)

Multilingual legal aid iOS app — petitioners with regional advocates. Voice-assisted forms, automated PDF reports.

Technologies: Swift, Firestore, PDFKit, STT

## [Fleet OS](/projects/fleet-os)

Git push to the hardware you already own. A Raspberry Pi, an old laptop and a spare VPS, treated as one deploy target — multi-arch builds, constraint-based placement, health-gated rollouts and automatic failover.

Technologies: Go, TypeScript, Fastify, Drizzle ORM, PostgreSQL, Redis, Docker Buildx, React, Vite, nginx, Cloudflare Tunnel
